# Pastor Thozi Gwanya — GitHub Pages Backup

This repository is the static backup and deployment mirror for the Pastor Thozi Gwanya landing page hosted on Zo Space.

The canonical production site is `https://thozi.zo.space/`. GitHub Pages publishes the static landing-page fallback at `https://uloyiso-community.github.io/pastor-thozi-gwanya/`.

## Deployment

The published page is the approved production source from Zo Space. Keep the landing page self-contained and preserve its original assets and interactions. Update `index.html` from the approved source when the Zo Space landing page changes.

GitHub Pages is configured to publish the `main` branch from the repository root.
